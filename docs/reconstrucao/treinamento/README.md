# Treinamento rápido (Fase 13)

Um roteiro curto por perfil, só com o que aquele perfil realmente usa (o menu de cada pessoa já mostra
só o que ela pode fazer: [papeis-permissoes.md](../papeis-permissoes.md)). Cada roteiro cabe numa
conversa de 20 a 30 minutos, de preferência na homologação, com dados de ensaio, antes da virada.

| Perfil | Roteiro | Duração sugerida |
|---|---|---|
| Proprietário | [proprietario.md](proprietario.md) | 40 min |
| Gerente | [gerente.md](gerente.md) | 30 min |
| Recepção | [recepcao.md](recepcao.md) | 30 min |
| Financeiro | [financeiro.md](financeiro.md) | 20 min |
| Profissional / barbeiro | [profissional.md](profissional.md) | 15 min (no celular dele) |

## Como conduzir

1. Cada pessoa entra com o **próprio usuário** (nunca uma conta compartilhada). No primeiro acesso o
   sistema pede para trocar a senha provisória.
2. Siga o roteiro fazendo as tarefas de verdade na homologação; não basta assistir.
3. No fim, a pessoa faz sozinha as tarefas marcadas com ✔ no roteiro. O que não der certo vira anotação
   para a homologação ([homologacao.md](../homologacao.md)).
4. Endereços: painel da equipe em `/painel/entrar`; área do profissional em `/profissional` (o barbeiro
   entra pelo mesmo login e cai direto nela); site e conta do cliente em `/` e `/entrar`.

## O que muda em relação ao sistema antigo (vale para todos)

- **Cada um tem o seu usuário.** Tudo o que importa fica registrado com o nome de quem fez.
- **Atendimento é a comanda.** O agendamento vira atendimento ao abrir; só conclui pago, e os pagamentos
  fecham exatamente com o total (não existe "pagar depois").
- **Um caixa por barbearia.** Dinheiro do atendimento só entra com o caixa aberto.
- **Desconto só com motivo** e só para proprietário e gerente; estorno só para proprietário e financeiro.
- **E-mails saem sozinhos** (confirmação, lembrete, comprovante); ninguém precisa mandar à mão.
